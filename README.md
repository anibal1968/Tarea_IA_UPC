# Tarea_IA_UPC

## Descripción
Repositorio de trabajo académico para organizar documentos y desarrollar actividades relacionadas con inteligencia artificial.

## Contenido

- `Convenio_imarpe_kiost.docx`: documento editable del convenio de cooperación entre IMARPE y KIOST.
- `Memorandum de entendimiento peru corea.pdf`: documento de referencia del memorándum de entendimiento entre Perú y Corea.
- `Memorandum_plantilla.docx`: plantilla editable para elaborar o revisar documentos.

## Objetivo
Mantener organizados los documentos de referencia y facilitar su consulta y actualización durante el desarrollo de la tarea.

## Observaciones
Verificar la versión, fecha y procedencia de cada documento antes de utilizarlo como fuente oficial.
